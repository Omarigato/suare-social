# SUARE SOCIALS · РУКОВОДСТВО ПО ПУБЛИКАЦИИ И АВТОМАТИЧЕСКОЙ ЗАЛИВКЕ

> **Проект:** SUARE (`suare.app`) — премиальные цифровые пригласительные на той, свадьбу, қыз ұзату, мерейтой.  
> **Каналы:** Instagram, Threads, TikTok, YouTube.  
> **Методы публикации:** Автоматический (CLI / API / n8n) и Ручной (готов к копированию).

---

## 1. БЫСТРЫЙ СТАРТ

### 1.1. Генерация всех картинок и обложек
```bash
# Генерация HTML-шаблонов
npm run generate

# Рендеринг всех PNG высокого разрешения через Chrome/Edge в exports/
npm run capture

# Или одной командой:
npm run build
```

Все готовые изображения сохраняются в папку `exports/`:
- `exports/instagram/post/` (1080×1350 — оптимальный формат 4:5 для ленты)
- `exports/threads/post/` (1080×1350 — 100% совместимо с Threads)
- `exports/tiktok/cover/` и `exports/instagram/story/` (1080×1920 — вертикальный 9:16)
- `exports/youtube/cover/` (1920×1080 — горизонтальный 16:9)

## 2. АВТОМАТИЧЕСКАЯ ЗАЛИВКА ПОСТОВ («ВЕЗДЕ»)

### 2.1. Публикация через единый CLI-диспетчер
```bash
# Тестовый прогон без реальной отправки (проверка валидации)
npm run post:dry-run

# Опубликовать пост во все платформы сразу (Instagram, Threads, TikTok, YouTube)
npm run post:all

# Публикация в конкретную соцсеть:
npm run post:ig        # Только Instagram
npm run post:threads   # Только Threads
npm run post:yt        # Только YouTube
npm run post:tt        # Только TikTok
```

### 2.2. Заливка через ваш запущенный n8n
У вас на компьютере уже работает `n8n`! Для мгновенной отправки любого поста в воркфлоу n8n:
1. Откройте интерфейс n8n (`http://localhost:5678`).
2. Нажмите **Import from File** и выберите файл:
   `toyga-social/n8n/suare-socials-workflow.json`.
3. Активируйте воркфлоу.
4. Выполните команду в терминале:
   ```bash
   npm run n8n:push
   ```
   Скрипт передаст сгенерированный медиа-пакет, текст, хэштеги и картинки в n8n, который разошлет их по всем подключенным соцсетям и пришлет отчет в Telegram.

## 5. ИНСТРУКЦИЯ ПО НАСТРОЙКЕ КЛЮЧЕЙ И ТОКЕНОВ (API)

Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

1. **Meta (Instagram & Threads):**
   - Зайдите на [developers.facebook.com](https://developers.facebook.com).
   - Создайте приложение типа Business.
   - В разделе **Instagram Graph API** сгенерируйте User Token с правами `instagram_basic`, `instagram_content_publish`.
   - Вставьте в `.env`: `INSTAGRAM_ACCESS_TOKEN` и `INSTAGRAM_ACCOUNT_ID`.
   - Для Threads добавьте продукт **Threads** и укажите `THREADS_ACCESS_TOKEN`.
2. **TikTok:**
   - Зайдите на [developers.tiktok.com](https://developers.tiktok.com).
   - Подключите Use Case **Content Posting API** (`video.upload`, `video.publish`).
   - Вставьте в `.env`: `TIKTOK_ACCESS_TOKEN`.
3. **YouTube:**
   - В [Google Cloud Console](https://console.cloud.google.com) включите **YouTube Data API v3**.
   - Создайте OAuth2 Client ID и получите токен с доступом `https://www.googleapis.com/auth/youtube.upload`.
   - Вставьте в `.env`: `YOUTUBE_ACCESS_TOKEN`.
