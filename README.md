# toyga-social

Заготовка. Здесь будет генерация контента для соцсетей: короткие видео и посты
для Instagram по данным мероприятия из `toyga-server`.

Пока пусто намеренно — стек не выбран, чтобы не тащить лишнего до первой реальной задачи.

## Что задумано

- Рендер вертикального видео 1080×1920 из данных мероприятия
  (обложка, имена, дата, место, QR на общую ссылку).
- Шаблоны сторис под казахские тои: үйлену тойы, қыз ұзату, тұсау кесер, мерейтой.
- Двуязычные варианты — қаз и рус.
- Отдача готового файла в MinIO, ссылка возвращается хозяину в кабинет.

## Открытые вопросы (решить перед первой строкой кода)

| Вопрос | Варианты |
| --- | --- |
| Чем рендерить | Remotion (React → mp4) · ffmpeg + шаблоны · Canvas → webm |
| Где рендерить | отдельный воркер · очередь в `toyga-server` · serverless |
| Публикация | руками скачал и выложил · Instagram Graph API (нужен Business-аккаунт) |
| Откуда данные | публичный `GET /api/i/:eventSlug` · отдельный служебный эндпоинт |

Пока публикацией в Instagram занимается человек — API требует Business-аккаунта,
review приложения и отдельного согласия хозяина на постинг от его имени.

## Связанные репозитории

- `toyga-server` — источник данных мероприятия
- `toyga-client` — гостевые приглашения
- `toyga-admin` — кабинет хозяина
